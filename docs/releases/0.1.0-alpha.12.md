# 0.1.0-alpha.12

Twelfth alpha. Kiekje reads the text in a region and copies it, and the overlay's modes answer to number keys.

## Text capture

- Text is a fourth overlay mode next to Screenshot, Video and GIF. Pick it in the top bar or with 4, select a region, and its text goes to the clipboard. Ctrl+T or Copy text does the same in the inline editor.
- `kiekje capture text`, a tray item and a `capture-text` shortcut without a default key start it directly.
- It runs locally with Tesseract, loaded at runtime, so Kiekje still starts without it. Settings, Capture, Text picks the languages, stored as `[text] languages` (default English). Without Tesseract every entry point is disabled with the reason, and `kiekje doctor` says what is missing.
- Install `tesseract` and the language data you need, for example `tesseract-data-eng` on Arch. The packages list it as optional.

## Overlay

- The keys 1, 2, 3 and 4 pick Screenshot, Video, GIF and Text, on the main row and the numpad. G still cycles them.
- The mode bar is opaque, as tall as the tool bar and set apart from it, so it no longer reads as part of the tool bar.
- Two GTK style warnings that every overlay and the tray popover logged are gone.

## Tested

`cargo fmt`, `cargo clippy -D warnings` and the unit tests pass (561 tests in the app, 11 in the lab probe). On KDE Plasma 6.7.5 the overlay showed the new mode bar, `kiekje doctor` reported Tesseract 5.5.3 with English and Dutch, and headless capture timing and storage errors were measured (see the lab results). The same preprocessing through the Tesseract CLI measured 1.1% character error on 60 rendered screen texts. Text capture from the overlay, the tray item and the shortcut have not been run end to end on a real desktop and are unverified. Hyprland and GNOME are untested.
