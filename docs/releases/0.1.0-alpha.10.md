# 0.1.0-alpha.10

Tenth alpha. Record just a region of the screen, straight from the overlay, and the inline editor now opens after every selection.

## Changed defaults

- `[capture] after_selection` now defaults to `"edit"`. Selecting a region keeps the overlay open with the drawing tools, and Accept, Copy or Save finishes the capture. If you want the old behaviour, where letting go of the mouse copies and saves, set `after_selection = "finish"` under `[capture]`.

## Record a region

- The overlay has three modes: Screenshot, Video and GIF. Press G to cycle them or use the buttons at the top of the overlay. With Video or GIF selected, a drag, a click on a window, F or Enter starts a recording of that region instead of taking a screenshot. The mode resets to Screenshot for every capture.
- The inline editor has Record (Ctrl+R) and Record GIF (Ctrl+Shift+R) next to Copy and Pin, so you can draw first and record afterwards. Record GIF also writes a GIF next to the WebM.
- The recording is cropped to the region. The region has to sit on one screen, and the screen the desktop's picker asks for must be the one you selected on.

## Starting and stopping

- A three second countdown runs before the recording starts, with one beep per second when `[notifications] sound` is on. It has no window of its own, so nothing of it ends up in the video. Escape on KDE, the record shortcut or Stop recording in the tray abandons the recording during the countdown.
- `[shortcuts] record` starts and stops a recording. It has no default key; set one under Settings, Shortcuts.
- On KDE Plasma, pressing Escape twice quickly or holding it for two seconds cancels the recording and deletes the file. Escape is a global key only while a recording runs, so other apps get it back as soon as the recording ends. Other desktops have no Escape cancel yet.
- Kiekje stores the ScreenCast restore token per source in `~/.local/share/kiekje/screencast-tokens.toml`. After the first grant, later recordings skip the desktop's picker. If a region recording ends up on a different screen than the one you selected on, Kiekje drops that token and stops with a message, so the next try shows the picker again.

## Tested

`cargo fmt`, `cargo clippy -D warnings` and the unit tests pass on the release commit (520 tests in the app, 11 in the lab probe). Region recording, the countdown, the Escape cancel on KDE and the restore tokens have not been run on a real desktop yet and are unverified. The recording pipeline itself was lab tested against a PipeWire source earlier. Hyprland and GNOME are untested. CI starts the binary and installs the packages on Arch, Fedora, openSUSE Tumbleweed, Debian trixie, Ubuntu 24.04 and Ubuntu 25.10, headless.
