# 0.1.0-alpha.7

Seventh alpha. Check, cross and emoji stamps in the editor.

## Editor

- Three new tools place a stamp with a click: Check (Y), Cross (U) and Emoji (I). A faded preview follows the pointer and shows the size. Checks and crosses use the current colour.
- Scroll changes the size of a stamp while a stamp tool is active or a stamp is selected.
- From the keyboard, the arrow keys move a stamp cursor (Shift moves it further) and Space places the stamp.
- Right-click with the Emoji tool, or press Menu or Shift+F10, opens the emoji picker. It has a search field and 64 common emoji, and accepts any emoji you paste. The button next to the tool opens it too and changes a selected emoji.
- Emoji need an emoji font. Kiekje uses Apple Color Emoji when it is installed and otherwise the system emoji font. The Apple font is not bundled.
- `[drawing.keys]` has three new keys: `check`, `cross` and `emoji`.

## Packaging

- Release runs started by hand now publish to the AUR and build the Flatpak, and the AUR step can read its SSH key.
- The Flatpak builds on GNOME 49 for a newer Rust.
- Emoji draw through `pangocairo`, which ships with Pango. No new system package is needed.

## Tested

The stamp rendering was checked in a headless render. The picker, the keyboard flow and scroll sizing are unverified on a real desktop (KDE Plasma, Hyprland, GNOME). CI starts the binary and installs the packages on Arch, Fedora, openSUSE Tumbleweed, Debian trixie, Ubuntu 24.04 and Ubuntu 25.10, headless.
