# 0.1.0-alpha.4

Fourth alpha. A cleaner annotation palette.

## Editor

- The tools, undo, redo and clear are icons in one rounded palette, with colours, size and opacity on the line below. Hover a tool to see its name and key.
- Colours are round dots, and the active one has a ring.
- The grey band behind the editor's toolbar is gone.
- The overlay's inline editor uses the same palette.

## Known issues

- GTK 4.14 (Ubuntu 24.04, Linux Mint 22) runs Kiekje without its styling. GTK 4.16 or newer is needed for the full look.
- The GNOME tray needs the AppIndicator extension.

## Tested

The editor window was rendered with GTK 4.20 under Xvfb. CI starts the binary and installs the packages on Arch, Fedora, openSUSE Tumbleweed, Debian trixie, Ubuntu 24.04 and Ubuntu 25.10, headless. The inline editor, capture, the overlay and the tray on a real desktop are unverified for this release on KDE Plasma, Hyprland and GNOME.
