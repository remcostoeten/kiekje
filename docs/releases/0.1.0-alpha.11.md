# 0.1.0-alpha.11

Eleventh alpha. Recordings get sound, the settings window is redesigned, and the screen can be captured to a file from a script.

## Recording with sound

- Screen recordings capture system audio, on by default, and optionally the microphone. With both on, they are mixed into one track. Settings has a switch for each, and the tray has a microphone toggle.
- `kiekje doctor` says whether the GStreamer parts for audio are installed.
- A capture shortcut may now share its key with the record shortcut. Pressing it captures when nothing records and stops a running recording. With a shared key, start a recording from the tray or with `kiekje record`.

## Settings

- The settings window is redesigned with a near-black palette, a full-height sidebar with a search field on `/`, and a Gallery link with the capture count.
- The Capture page opens with a live preview of the overlay that follows your settings. Hovering a row lights the part it controls.
- Text is one step larger, and a GTK theme in `~/.config/gtk-4.0/gtk.css` can no longer recolour Kiekje.
- Global shortcuts pause while you record a new shortcut.
- Minimize, maximize and close are back, and the sidebar buttons have accessible names for screen readers.

## Capture to a file

- `kiekje capture fullscreen --output PATH` and `kiekje capture window --id ID --output PATH` write one PNG or JPEG without the overlay, the clipboard, a notification or a gallery entry. `--crop x,y,w,h` keeps part of it. Window capture goes through KWin, so a window behind others comes out whole. Plasma only.
- `kiekje windows` lists the open windows with their ids.

## Tested

`cargo fmt`, `cargo clippy -D warnings` and the unit tests pass on the release commit (548 tests in the app, 11 in the lab probe). The headless capture commands were run on KDE Plasma 6. The pin zoom, editor undo while typing and settings persistence checks from issue 41 pass on a private Xvfb display. Recording with audio and the shared shortcut key have not been run on a real desktop and are unverified. Hyprland and GNOME are untested. CI starts the binary and installs the packages on Arch, Fedora, openSUSE Tumbleweed, Debian trixie, Ubuntu 24.04 and Ubuntu 25.10, headless.
