# Releases

Kiekje ships as pre-release alphas from [GitHub Releases](https://github.com/remcostoeten/kiekje/releases). Each release carries x86_64 and aarch64 tarballs, `.deb` and `.rpm` packages, a Flatpak bundle, the two PKGBUILDs and `SHA256SUMS`. The notes below are the same text as the release body on GitHub.
