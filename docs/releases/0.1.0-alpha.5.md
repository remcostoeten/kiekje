# 0.1.0-alpha.5

Fifth alpha. Styling on GTK 4.14, straight lines, JPEG saving and an in-app capture sound.

## Desktops

- Ubuntu 24.04, Linux Mint 22 and other GTK 4.14 systems now get the full styling. The stylesheet is flattened to plain values at build time.

## Editor

- Hold Shift while drawing for straight lines at 45 degree steps (line, arrow, pen) and squares or circles (box, ellipse).

## Saving and gallery

- Settings > Saving has a Format group: PNG or JPEG, with a quality slider for JPEG. The clipboard always gets PNG.
- The gallery shows each capture's file type next to its size.
- Rename a capture from the gallery with F2.

## Capture sound

- Kiekje plays the capture sound itself, from the sound theme's shutter or a bundled fallback, so it also works with notification daemons that ignore sound hints, such as mako. It needs the GStreamer base plugins; the packages pull them in and the AUR packages list them as optional.
- Without the GStreamer base plugins Kiekje logs a warning and keeps running instead of crashing on capture.

## Known issues

- The GNOME tray needs the AppIndicator extension.

## Tested

The GTK 4.14 styling was rendered on Ubuntu 24.04 (GTK 4.14.5) under headless sway. Shift drawing, the save format, rename and the capture sound were tested in a headless lab only. CI starts the binary and installs the packages on Arch, Fedora, openSUSE Tumbleweed, Debian trixie, Ubuntu 24.04 and Ubuntu 25.10, headless. Everything in this release is unverified on a real desktop (KDE Plasma, Hyprland, GNOME).
