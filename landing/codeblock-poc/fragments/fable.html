Install

Kiekje 0.1.0-alpha.12 is a pre-release. The binary links gtk4-layer-shell statically, so the only runtime dependency is GTK 4.14 or newer. Every release has x86_64 and aarch64 builds with a SHA256SUMS file.

v0.1.0-alpha.12

Start it with kiekje daemon, then run kiekje doctor to see what your session supports. Plasma needs kiekje install-desktop-file once, Hyprland the source line that doctor prints. Getting started
